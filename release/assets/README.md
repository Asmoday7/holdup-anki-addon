# HoldUp example screenshots

These screenshots were supplied by the project owner in `ExampleAnki_full.zip`.
They show the English Anki interface with Japanese sentence cards. The selected
PNG files are published byte-for-byte from the archive, preserving all card
content, counters and controls.

Eight of the eleven supplied frames illustrate the stages used in the listing:

The listing opens with the compact `example-08-ready-badge.png` deck-row preview,
then follows the workflow: interval, original answer, scheduled appearance,
deck list, deck overview, practice question and practice answer.

| File | State |
| --- | --- |
| `example-01-normal-review.png` | Normal answer with the four Anki ratings and HoldUp. |
| `example-02-holdup-scheduled.png` | HoldUp checked, waiting count increased, normal ratings still available. |
| `example-03-practice-question.png` | Question side of extra practice in the same reviewer. |
| `example-04-practice-answer.png` | Answer side of extra practice with Repeat, Done and interval controls. |
| `example-05-interval.png` | Interval dialog with custom seconds and Next Anki study day. |
| `example-06-deck-overview.png` | Deck overview with waiting/ready HoldUp status and Continue studying. |
| `example-07-deck-list.png` | Deck list showing HoldUp ready badges alongside native Anki counts. |
| `example-08-ready-badge.png` | Close-up of the green clock badge for one ready HoldUp appearance. |

The four original image paths remain as compatibility copies of these new
screenshots so descriptions that already use those URLs also receive the new
examples. The main listing uses the new `example-*.png` filenames.

These are owner examples, separate from the automated validation evidence in
[VALIDATION.md](../VALIDATION.md).
