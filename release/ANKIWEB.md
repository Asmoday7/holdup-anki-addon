# HoldUp 1.0.0: полный гайд по публикации

Этот гайд ведёт от готового релиза до установки пользователем по коду AnkiWeb.
Собирать или программировать что-либо на этом этапе не требуется.

## 1. Что уже готово

- **[Стабильный релиз 1.0.0 на GitHub](https://github.com/Asmoday7/holdup-anki-addon/releases/tag/v1.0.0)** опубликован.
- Установочный файл проверен: 236 тестов в каждом из четырёх Windows/Linux-прогонов.
- В одном пакете есть русский и английский интерфейсы; язык следует настройке Anki.
- Подготовлены описание, скриншоты, лицензия и инструкции.
- В описание уже включены Boosty, DonatePay и планы колод по веб-новеллам независимо от донатов.

Следующее действие владельца — загрузить этот файл на AnkiWeb через свой аккаунт.

## 2. Скачайте файл и откройте описание

**Скачайте:** [holdup-1.0.0.ankiaddon](https://github.com/Asmoday7/holdup-anki-addon/releases/download/v1.0.0/holdup-1.0.0.ankiaddon).

Оставьте файл целиком в папке загрузок: он уже упакован для Anki.

**Откройте во второй вкладке:** [готовое HTML-описание](https://raw.githubusercontent.com/Asmoday7/holdup-anki-addon/main/release/ankiweb-description.html).

На странице будет текст с `<p>`, `<a>`, `<li>` и другими тегами — это готовая
разметка описания. Нажмите **Ctrl+A → Ctrl+C**, затем вставьте её в поле описания
формы AnkiWeb через **Ctrl+V**. Ссылки на скриншоты и поддержку уже внутри.

Для редактора, который принимает только обычный текст, подготовлен
[текстовый вариант](https://raw.githubusercontent.com/Asmoday7/holdup-anki-addon/main/release/ankiweb-description.txt).
Он нужен только если HTML не поддерживается или показывается читателям как код.

## 3. Войдите на AnkiWeb и откройте загрузку

1. Откройте https://ankiweb.net/shared/addons.
2. Войдите в аккаунт AnkiWeb, который будет владельцем дополнения.
3. Нажмите **Upload**. Если сначала открылась авторизация, после входа вернитесь
   на страницу дополнений и нажмите Upload.

Официальное руководство подтверждает загрузку `.ankiaddon` через эту кнопку.
Авторизованная форма из среды подготовки недоступна, поэтому точные названия
остальных полей не проверялись. Таблица ниже задаёт их содержание; дополнительные
поля заполняются, если они действительно есть в форме.

В предпросмотре, если он есть, проверьте:

- заголовки и списки оформлены, теги HTML не видны как обычный текст;
- картинки открываются;
- ссылки ведут на GitHub, Boosty и DonatePay;
- написано, что аддон бесплатный, а поддержка добровольная;

установка на коллекцию, непроверенная синхронизация очереди
между устройствами. Полный перенос очереди поддержан через `.colpkg`/резервную
копию, а не через экспорт одной колоды `.apkg`.

## 6. Опубликуйте и сохраните адрес и код

Завершите публикацию действием, которое предлагает форма. После её завершения
сохраните:

- **адрес страницы дополнения** — для пользователей, анонсов и README;
- **числовой код дополнения** — для установки внутри Anki;
- доступ к аккаунту владельца — для последующих обновлений этой же страницы.

Страница дополнения, код AnkiWeb и ссылка на GitHub выполняют разные задачи.
В окно «Загрузить дополнения» в Anki вводится выданный сайтом числовой код.

Файл версии 1.0.0 уже опубликован на GitHub. Для следующих обновлений используйте
ту же страницу AnkiWeb и тот же код.

## 7. Проверьте установку именно с AnkiWeb

Это короткая проверка способа распространения по коду, после уже выполненного
недельного тестирования механики.

1. В Anki откройте **Инструменты → Дополнения**. Если старая ручная копия HoldUp
   включена, отключите её и перезапустите Anki перед установкой по коду.
2. Создайте временный тестовый профиль через меню смены профиля.
3. Откройте **Инструменты → Дополнения → Загрузить дополнения**, вставьте полученный
   код, подтвердите установку и перезапустите Anki.
4. Убедитесь, что включена одна копия HoldUp. Если ручная и установленная по коду
   копии отображаются одинаково, папку можно посмотреть через действие
   «Просмотреть файлы» / View Files: у ручной обычно имя `holdup`, у AnkiWeb —
   числовой код.
5. Добавьте в тестовом профиле одну карточку, откройте её ответ, через **⋯**
   поставьте интервал **15 секунд**, нажмите **HoldUp**, затем обычную **Легко**.
6. Выполните **Правка → Отменить**. Должен вернуться оригинал с обычными оценками,
   а назначенный дополнительный повтор — сохраниться. Снова оцените оригинал.
7. Когда срок наступит, продолжите изучение этой колоды. Дополнительный показ
   должен открыться в том же окне с пометкой HoldUp. Покажите ответ, нажмите
   **Готово**, затем отмените действие: дополнительный показ должен вернуться.
8. Вернитесь в основной профиль и выберите свой обычный интервал HoldUp.

**Дополнения и их настройки в одной установке Anki общие для профилей.**
Тестовый профиль разделяет коллекции, но не создаёт отдельный набор дополнений.
После теста интервал 15 секунд тоже нужно сменить на привычный.

Назначения HoldUp хранятся в коллекции: отключение прежней ручной копии не удаляет
очередь основной коллекции. Локальный интервал у новой установки при необходимости
выберите заново. Подробное поведение — в [русской инструкции](../USER_GUIDE.ru.md).

## 9. Как выпускать обновления

Для исправлений используйте следующую версию, например `1.0.1`. Номер обновляется
внутри пакета, после чего собирается новый релиз с проверками. Самого переименования
файла недостаточно.

На AnkiWeb откройте свою существующую страницу дополнения в аккаунте владельца,
загрузите новый файл и описание изменений. Сохраните прежний код: по нему
пользователи будут получать обновления. При изменении проверенной совместимости
обновите соответствующие сведения.

## Если что-то не получилось

- **Форма принимает только ZIP:** [holdup-1.0.0.zip](https://github.com/Asmoday7/holdup-anki-addon/releases/download/v1.0.0/holdup-1.0.0.zip)
  содержит те же байты. Загрузите его, если форма явно просит расширение ZIP.
- **Видны теги `<p>` и `<a>`:** если у редактора есть режим HTML/Source, используйте
  его. Для поля без HTML есть [готовый обычный текст](ankiweb-description.txt).
- **Кнопка HoldUp показывается дважды:** оставьте включённой одну копию дополнения
  в Инструменты → Дополнения и перезапустите Anki.
- **Дополнительный показ не появляется сразу:** он становится готовым в выбранный
  срок и не прерывает текущую карточку. Для теста нужен короткий интервал и
  продолжение изучения нужной колоды.

## Что подтверждено

[Официальное руководство Anki](https://github.com/ankitects/anki/blob/main/docs-site/addons/sharing.mdx)
подтверждает `.ankiaddon`, отсутствие внешней папки в ZIP, запрет `__pycache__`
и кнопку Upload на странице дополнений. Дополнения/настройки, общие для профилей,
сверены с кодом Anki. Релиз и готовое описание проверены по опубликованным файлам.

Авторизованной сессии AnkiWeb здесь нет; сам сайт из среды подготовки отвечает
отказом доступа. Поэтому публикация на AnkiWeb и установка по будущему коду
пока не заявляются как выполненные.
